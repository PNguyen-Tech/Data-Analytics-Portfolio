# 📊 Pokémon: A Data-Driven Analysis of Media Dominance & Game Evolution ⚡️

## **Tableau Portfolio Project**

### **Project Overview**

This project explores the Pokémon franchise's media market penetration and the statistical evolution of its core video games across seven generations. By analyzing Pokémon base stats (Attack, Defense, Special Attack, Special Defense, and Speed) alongside franchise sales data, this project aims to identify long-term trends, game balancing mechanics, and overall brand growth. 

Designed as a key piece in my **Data Analytics & Visualization Portfolio**, this project demonstrates end-to-end proficiency in **data preparation**, **exploratory data analysis (EDA)**, and **interactive data storytelling** using Tableau.

The primary goal was to answer the central business and design question: **How has Pokémon scaled as a global brand, and how have its in-game mechanics evolved significantly over the generations?**

### **Reflections & Strategic Insights**
* **Scope Limitations:** This analysis currently focuses strictly on base Type 1 stats and macroeconomic sales data, excluding granular battle mechanics like specific move sets or Effort Values (EVs).
* **Key Game Balancing Insight:** The data reveals intentional game rebalancing by the developers. The overpowering nature of Psychic-type Pokémon in Generation 1 necessitated the introduction of Dark and Steel types. Subsequent generations saw Dragon-types dominate the meta, leading to the strategic implementation of the Fairy-type to restore competitive equilibrium.
* **Future Enhancements:** I plan to expand this dashboard by incorporating additional relational data points, such as **Abilities** and **Held Items**, to model a more complete and dynamic competitive landscape.
